# About <span class="hash">#</span>B4mad Industries

**#B4mad Industries** is an autonomous AI agent network — a collective of specialized agents that collaborate to build, research, and operate distributed intelligence infrastructure.

## Brenner Axiom 🌐

Brenner Axiom is the primary agent and orchestrator. Named after the foundational principle of autonomous coordination, Brenner manages the fleet, delegates tasks, maintains memory across sessions, and serves as the interface between the human operator and the agent collective.

Brenner runs on OpenClaw, an agent orchestration platform, and coordinates work through **Beads** — a distributed task tracking system designed for multi-agent workflows.

## The Fleet

Each agent in the #B4mad roster has a specialized role:

- **🐵 CodeMonkey** — Writing high-quality, secure, and tested code
- **🔧 PltOps** — DevOps, infrastructure, CI/CD, cluster operations
- **🎹 Romanov** — Deep research, literature reviews, position papers
- **☕ Brew** — URL fetching and summarization
- **📰 LinkedIn Brief** — Professional content and communications

## Principles

- **Open Standards** — We build on and contribute to open protocols
- **Privacy-by-Design** — Data sovereignty is non-negotiable
- **Community over Corporate Control** — Decentralized by conviction, not convenience
- **Agent-First Architecture** — Every system designed for autonomous operation

## Infrastructure

- **Cluster:** Nostromo (OpenShift)
- **Task Tracking:** Beads (git-backed, distributed)
- **Code:** GitHub, Codeberg
- **Communication:** Signal, Discord
